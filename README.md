## 📦 Developer info

[![Automatic tests level](https://apps.yunohost.org/badge/cilevel/iptvtunerr)](https://ci-apps.yunohost.org/ci/apps/iptvtunerr/)

🛠️ Upstream IPTV Tunerr repository: <https://github.com/snapetech/iptvtunerr>

Pull request are welcome and should target the [`testing` branch](https://github.com/YunoHost-Apps/iptvtunerr_ynh/tree/testing).

The `testing` branch can be tested using:
```
# fresh install:
sudo yunohost app install https://github.com/YunoHost-Apps/iptvtunerr_ynh/tree/testing

# upgrade an existing install:
sudo yunohost app upgrade iptvtunerr -u https://github.com/YunoHost-Apps/iptvtunerr_ynh/tree/testing
```

You can also switch to the testing branch to update from testing by default (as same as for APT when you chose to use a testing repos) with this command:
```bash
sudo yunohost app setting iptvtunerr upgrade_channel -v testing
```
